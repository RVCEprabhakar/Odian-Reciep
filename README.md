# Recipe Details for Bachelors

This project is a simple HTML-based webpage that provides details of different recipes, including their descriptions and ingredients. It is designed to help beginners learn how to structure and style content using HTML.

## Features

- **Recipe List**: Includes three recipes:
  - Chapati
  - Chole Butter
  - Chapati and Curry
- **Ingredients**: Each recipe has a detailed list of ingredients.
- **Links to Images**: Each recipe includes a link to an image for visual reference.
